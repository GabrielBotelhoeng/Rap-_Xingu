# Story 1.2 — Hero com fotos padronizadas, destaques redesenhados e celular

**Status:** Done (prévia aprovada pelo usuário e mesclada no `main`) · **Branch:** `feat/1.2-hero-destaques-mobile` · **Origem:** pedido do usuário em 2026-10-01 (sessão 3)

## Pedido

1. **Hero:** o usuário gostou da troca de cor de fundo junto com o produto. Agora há fotos no mesmo padrão (lata aberta + tampa,
   fundo branco) de 4 sabores: Puro Tabaco, Eucaliptu’s Selva, Super Mentolado e Puro Vick.
   - A palavra grande atrás do produto fica ilegível porque o produto a cobre → corrigir.
   - Colocar coisas flutuando no fundo (muitas latinhas com um pouco de opacidade, mais elementos ligados ao rapé).
2. **Destaques ("Os mais pedidos"):** achou feio — ervas que parecem "mudas de árvore", rolagem travada (pin), fontes
   exóticas. Quer um efeito que chame atenção, mas bonito.
3. **Celular:** tudo funcionando 100%.
4. Higgsfield liberado sem aprovação prévia nesta rodada (o usuário saiu), com os melhores modelos; continua valendo:
   nada de IA para gerar latinha.

## Critérios de aceite

- [x] Os 4 sabores fotografados aparecem no hero com as fotos novas recortadas, todas no mesmo padrão de tamanho e luz
- [x] A palavra do hero fica legível em todos os tamanhos: o produto cobre no máximo a base das letras (checagem automática no `npm run shots`)
- [x] Fundo do hero com latinhas e elementos do rapé flutuando, com opacidade e profundidade; leve no celular; parado com movimento reduzido
- [x] Destaques sem pin (rolagem livre), sem as ervas, com tipografia limpa e um efeito de abertura da latinha ligado ao scroll
- [x] Celular: hero, destaques, catálogo, formulário, menu e barra de WhatsApp sem sobreposição nem corte em 375, 390 e 768 px (e alturas do Safari)
- [x] Build, lint, typecheck e testes passando; `npm run shots` sem problemas, com e sem movimento reduzido
- [x] Prévia publicada no GitHub Pages para revisão (o `main` só recebe depois do ok do usuário)
